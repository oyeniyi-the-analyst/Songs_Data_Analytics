# Songs Data Analytics Project

This project focuses on transforming raw music data into a clean and reliable dataset, and analysing how song characteristics change over time.


## Business Problem

Music datasets collected from different sources often contain:

- Missing values  
- Invalid data  
- Inconsistent formatting  

This makes analysis unreliable and difficult.


## Approach

I designed a structured data pipeline using SQL to clean, validate, and transform the data before analysis.

The cleaned dataset was then used to analyse trends in song characteristics.


## Key Insights

- Music characteristics evolve over time  
- Tempo trends highlight changes in musical style  
- Loudness trends reflect production changes
